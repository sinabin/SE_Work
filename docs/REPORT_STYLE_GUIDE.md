# Report Style Guide

## 기본 스타일

- 용지: A4
- 분위기: 공공기관/운영 결과보고서
- 폰트: 맑은 고딕 계열
- 좌우 여백: 넓게
- 페이지 번호: 기본 미사용
- 각주: 기본 미사용
- 장황한 서론보다 결론/현황/조치/결과 중심

## 1장 보고서 권장 구조

```text
제목

1. 점검 개요
2. 주요 확인 결과
3. 조치 내용
4. 최종 결과 / 향후 계획
```

표 컬럼은 가능하면 다음처럼 단순하게 유지한다.

```text
대상 | 현황 | 조치 | 결과 | 비고
```

## 취약점 업체 회신용

가능하면 다음을 구분한다.

```text
항목 | 조치 가능 여부 | 조치 기준 | 불가/예외 사유 | 일정
```

## 기술 보고서

운영 스크립트/아키텍처 분석 시 다음 원칙을 따른다.

- 실제 경로와 명령어를 코드블록으로 명시
- 확인된 사실과 추정을 구분
- 변경 금지/주의 항목을 별도 정리
- 재현 가능한 확인 명령 포함
